# **App Name**: PaperTrail Portfolio

## Core Features:

- Publication Listing: Display a list of publications, with title, abstract and link to the full paper (hosted elsewhere as PDF).
- Paper Categorization: Categorize papers by topic (Data Science, ML, Applied Math).
- About Me Section: Provide a brief author bio and contact information.
- AI Paper Summary: Use an AI tool to generate a short summary 'elevator pitch' for each paper. This short description can be shown to the user to help them decide whether to read the paper.
- Contact Form: Implement a simple contact form for inquiries.
- Executable Notebook Snippets: Embed executable Jupyter Notebook snippets directly within the paper entries, allowing users to interact with code examples.

## Style Guidelines:

- Use a professional and clean color palette. Primary color: White or light gray for the background.
- Secondary color: Dark gray or black for text to ensure readability.
- Accent: Teal (#008080) for interactive elements and highlights.
- Use clear and readable typography for paper titles and abstracts.
- Use a clean and organized layout to showcase papers effectively.
- Use subtle icons to represent paper categories (e.g., a chart for Data Science).
- Subtle hover effects on paper entries to indicate interactivity.

## Original User Request:
A personal website for my portfolio of amateur Data Science and Machine Learning papers, along with my Applied Mathematics Technical Papers/Research.
